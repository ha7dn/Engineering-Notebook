### How to push code from VS Code to Github
1. Install git
2. Run these commands on a terminal in the project's folder
```
git init
git remote add origin https://github.com/ha7dn/Engineering-Notebook.git
git config --global user.email "h.mengue.eworo@hotmail.com"
git config --global user.name "sam"
git clone https://github.com/ha7dn/Engineering-Notebook.git

```

Official docs: https://code.visualstudio.com/docs/sourcecontrol/overview
