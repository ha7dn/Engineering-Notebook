I started configuring my dev environment. I installed Docker Desktop, Terraform and created a container for an SQL database for Fleetly, a side project to manage VTCs (MooveFleet, basically).
I learned how to create a container, how to pull an image from Microsoft's Registry and use it to create a container, and how to create a container that persists the data even when it's deleted (by creating the volume - which contains the data, separated from the container itself).
